## Limitations and unavailable evidence

1. No run stores a macro-F1 value. Macro-F1 is independently recomputed for every run; there is no stored macro-F1 field available for direct comparison, so no claim of stored-macro-F1 reproduction is made.
2. The reference runs contain no checkpoint.pth. Their weights are the separately verified recovered checkpoints, recorded per seed as a linkage rather than reported as a missing artifact.
3. dataset_clean/Testing holds no images locally, so the canonical mapping was derived from the split manifest (preferred source 1) and could not be cross-checked against a directory enumeration.
4. The external 499-image predictions were validated for structure only. External labels are not used for tuning or model selection.
5. Phase 3A manifests were left exactly as issued, so this addendum is an additive record of what was checked later.
6. The reference runs do not record whether the fusion gate was active. src/fusion_v2.py constructs the gate module unconditionally and only skips using it in forward(), so the recorded parameter count is identical with and without gating and cannot settle the question; src/train_ablation.py guards its gate dump on the architecture only, so the presence of gate telemetry in the reference runs does not settle it either. The reference value is therefore taken from the reference specification in run_ablations.py, corroborated by all seven reference fields that ARE recorded agreeing with that specification. This is the weakest evidence class used in this addendum and it is the basis on which the no_gate comparison rests.
7. The reference runs record no patience, val_fraction or val_split_seed. Those values are read as module-level literals from src/train_ablation.py, whose digest is recorded; that file imports torch, which is not installed locally, so it was parsed rather than executed. This is code-level evidence, not a recorded value from the run.
8. The reference multiscale setting is not recorded either. It is derived from the parameter count the reference itself recorded, which matches only the multiscale cohort of the imported fusion runs and differs from the non-multiscale cohort by 77,824 parameters.
