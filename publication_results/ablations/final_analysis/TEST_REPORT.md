# Phase 3B - Final Analysis Test Report

Generated by `src/publication/test_final_analysis.py`.

**41 of 41 tests passed. Status: PASS.**

Two kinds of test are here and both are needed. **Rejection tests** break exactly one thing in a synthetic run and assert the analyser refuses it. **Formula tests** check the arithmetic against values computed by hand or by an independent method, because a validator that only ever accepts clean data says nothing about whether its numbers are right.

Several tests assert the opposite direction, so a suite that rejected everything could not pass: a genuine top-two tie is accepted and counted rather than rejected; reversing the row order must change nothing; identical predictions must give a zero-width bootstrap interval; and a correct reference-spec agreement must be usable.

Three tests pin protocol guarantees that are easy to violate silently: the Holm family must be 21 and refuse both 7 and 2,544; a paired comparison across two different seeds must be refused; and the verdict vocabulary must contain no equivalence claim.
