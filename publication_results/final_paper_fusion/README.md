## Submission blockers requiring author input

Before journal submission, replace every `[AUTHOR INPUT REQUIRED]` field. Confirm authors and ORCIDs, affiliations, corresponding-author details, target venue, institutional ethics determination, dataset licensing, funding, competing interests, CRediT roles, repository URL, archival DOI, acknowledgements and the venue-required generative-AI disclosure. Training and inference timing should be measured if the selected venue requires it.

The BRAIN-META comparison is deliberately contextual. Do not rewrite it as statistical superiority unless BRAIN-META is reproduced on the identical split or its aligned per-image predictions become available.
